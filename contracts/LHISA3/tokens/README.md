# Fungible Tokens

Questa cartella contiene i token fungibili che rappresentano valore, memoria e impatto nel sistema Solidary.

## Moduli inclusi

- **LecceFT.sol**  
  Token commemorativo fungibile legato al progetto Lecce. Supporta mint e burn.

- **SolidaryToken.sol**  
  Token base del sistema Solidary, utilizzato per transazioni etiche.

- **SolidityLecceFT.sol**  
  Variante del LecceFT con logiche di testimonianza e valore simbolico.

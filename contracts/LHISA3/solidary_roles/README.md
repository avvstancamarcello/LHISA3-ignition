# Ethical Role Modules

Questa cartella contiene i moduli dedicati alle categorie utente etiche. Ogni modulo gestisce un token commemorativo e una funzione orbitale.

## Moduli inclusi

- **SolidaryEduToken.sol** – Educatori scolastici  
- **SolidaryFaithToken.sol** – Enti religiosi  
- **SolidaryGovToken.sol** – Enti pubblici  
- **SolidaryHeartBridge.sol** – Naviganti  
- **SolidaryJusticeManager.sol** – Operatori carcerari  
- **SolidaryPeaceManager.sol** – Militari  
- **SolidarySocialMint.sol** – Volontari sociali  
- **SolidarySoulBridge.sol** – Operatori spirituali  
- **SolidarySponsorVault.sol** – Sponsor wallet  
- **SolidaryUnivManager.sol** – Studenti universitari

Ogni modulo include funzioni di mint etico, eventi di 
testimonianza e ruoli granulari.

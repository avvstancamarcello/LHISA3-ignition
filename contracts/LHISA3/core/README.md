# Core Modules

Questa cartella contiene i moduli infrastrutturali del sistema Solidary. Gestiscono il routing, il tracciamento dell’impatto e la reputazione etica.

## Moduli inclusi

- **ModuleRouter.sol**  
  Gestisce il collegamento tra moduli e il routing delle funzioni etiche.

- **ImpactLogger.sol**  
  Registra gli impatti solidali generati dagli utenti, con verifica del bilancio.

- **ReputationManager.sol**  
  Gestisce la reputazione etica degli attori del sistema, basata su testimonianze e azioni.

# NFT Modules

Questa cartella contiene i moduli NFT commemorativi e gestionali. Ogni NFT rappresenta una memoria, una testimonianza o un impatto etico.

## Moduli inclusi

- **LHILecceNFT.sol / v2 / flattened**  
  NFT commemorativi legati al progetto Lecce. Versioni aggiornate e ottimizzate.

- **LHIManagerNFTNonFungibileToken.sol / flattened / cleaned / backup**  
  Gestione avanzata degli NFT con ruoli e metadati solidali.

- **LHIPropertyToken.sol**  
  NFT che rappresenta proprietà etica o testimonianza personale.

## 🚀 Deployment Instructions

### Quick Start
```bash
cd lunacomics-ethernum
npm install
npm run dev
```

### Production Build
```bash
npm run build
# Output: dist/ directory ready for deployment
```

### Environment Setup
Users need to copy `.env.example` to `.env` and optionally add:
- WalletConnect Project ID (optional)
- Pinata API keys (optional, for IPFS)
